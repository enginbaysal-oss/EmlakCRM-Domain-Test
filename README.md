# EmlakCRM – Domain ve HTTPS Testi

Bu depo yalnızca **emlkcrm.com.tr** özel alan adını ve HTTPS sertifikasını doğrulamak için hazırlanmıştır.

- Üretim sitesi: https://enginbaysal-oss.github.io/EmlakCRM-Web/
- Bu depo kişisel veri, şifre, giriş, ödeme veya Supabase erişimi içermez.
- GitHub Pages kaynağı: **Deploy from a branch** → `main` → `/(root)`.
- Bu depodaki `CNAME` yalnızca test sitesine bağlanır.
- HTTPS doğrulanmadan üretim uygulaması veya Android APK yönlendirilmez.
- Alan adı üzerinden sadece test sayfası görüntülenir.

Test başarılı olsa bile EmlakCRM kullanıcılarının tarayıcıya bağlı verileri otomatik olarak yeni alana taşınmaz; gerçek geçiş ayrı ve yedekli yapılmalıdır.
